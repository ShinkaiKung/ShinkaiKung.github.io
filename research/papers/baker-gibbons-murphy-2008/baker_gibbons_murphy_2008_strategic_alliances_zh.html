Strategic Alliances: Bridges Between “Islands of Conscious Power”

George P. Baker · Robert Gibbons · Kevin J. Murphy · March 2008

JEL D2L14L22Strategic alliancesTheory of the Firm

这篇论文问的是：当两个独立企业需要共同推进一个项目时，我们为什么不能只用“market vs. integration”来理解组织选择？作者把 governance 定义为 assets、decision rights 与 payoffs 的配置，并把两个 friction 放在中心：联合项目对母公司的 spillovers，以及关键行动的 ex post noncontractibility。

AUTHOR'S ARGUMENT

Strategic alliances 是跨越企业边界的 contractual “bridges”。不同的 bridge 会让不同主体内生化不同部分的 surplus，因此现实中多种组织形式都可能是 second-best；不存在一个在所有环境中都最优的 governance form。

Source: Abstract and §1 · PDF pp. 1–6 · source map

1. 核心问题：从 “Islands” 到 Contractual Bridges

1.1 Market–firm dichotomy 太粗糙

现实中的 strategic alliances 从 unstructured collaboration、consortia、joint ventures，一直到改变 asset ownership 的交易都有。Pharmaceuticals、biotechnology、medical devices、airlines 和 telecommunications 中的组织形式，远多于简单的 “market vs. firm” 二分法能够描述的范围。

标题沿用 firms as “islands of conscious power” 的比喻。作者并不否认 firm boundaries，而是强调：要画出真实的 institutional structure of production，必须同时画出跨越边界、移动 decision rights 与 payoffs 的 contractual bridges。

Island

边界清晰；authority 与 ownership 主要集中在 firm 内部。

Bridge

在 firm boundaries 固定时，通过 contract 跨边界配置 decision rights/payoffs。

Hybrid

Joint ventures 等形式在既有 parent firms 之上叠加新的 governance。

Source: §1 · PDF pp. 2–5

1.2 Practitioners 真正强调了什么？

AUTHOR'S ARGUMENT

Spillovers / externalities： joint project 可能帮助或伤害 parent firms 的 core activities。

AUTHOR'S ARGUMENT

Ex post contracting problems：state 出现以后，关键行动往往无法被 contract，因此 governance 必须事先设计好 ex post incentives。

QUALIFICATION

Specific-investment hold-up 与 bargaining over returns 仍然是 organizational economics 的经典机制，但在作者的 practitioner interviews 中，它们明显没有 spillovers 与 ex post adaptation 那么突出。

Source: §1 · PDF pp. 2–3

3. 模型（Model）：Assets、Spillovers 与 Ex Post Control

3.1 Economic Environment

经济中有四个 assets：{A, a, B, b}，初始有两家 firms。Firm A 拥有 core asset A 与 project asset a；Firm B 拥有 core asset B 与 project asset b。只有当 a 与 b 被协调使用时，联合项目才产生 direct profits。

Assets and decisions

每个 project asset i∈{a,b} 都包含一个 decision right di 与 direct payoff πi。协调使用时 πa>0、πb>0；否则 direct project payoff 为 0。

State and spillovers

Observable-but-unverifiable state s 生成 parent firms 的 private benefits πA(s) 与 πB(s)，它们可以为正或负，joint distribution 为 F；论文进一步假定二者具有有限 support：[π̲A, π̄A] 与 [π̲B, π̄B]。

CONTRACTIBILITY LADDER

State s：observable, not verifiable。Spillovers πA,πB：observable private benefits, not contractible。Decisions：not contractible。Decision rights：可以在后续模型中通过 contract 转移。Direct project payoffs πa,πb：起初与 asset ownership 绑定，§3e 再假设可 contract，以允许 royalty contracts。

Source: §3a · PDF pp. 8–10; Figure 3 · PDF p. 9

3.2 Timing 与 Ex Post Contracting Problem

1
Ex ante 选择 governance

通过 ownership 和/或 contracts 配置 decision rights 与 payoffs；如有需要可以有 ex ante side payments。

2
State s realized

双方观察到实际 spillovers。

3
Controllers 选择 da, db

每个 decision-right holder 根据自己的 private payoff criterion 行动。

4
Payoffs accrue

Asset owners 或 royalty holders 获得 direct payoffs；parent firms 获得自己的 private spillovers。

ASSUMPTION 1 · FLEETING OPPORTUNITY

s 出现以后，机会窗口太短，无法在行动前重新 contract decision rights 或 payoffs。

ASSUMPTION 2 · NONCONTRACTIBLE DECISIONS

具体 actions 无论在 s 出现前还是之后都不能写入 enforceable contract，因此排除了对决策进行 ex post Coasian bargaining。

3.4 First Best，以及为什么主分析排除 Full Merger

First-best implementation criterion
πA(s) + πB(s) + πa + πb > 0

含义：只有当 joint project 的 total social surplus——包括两家 parent firms 的 spillovers——为正时才实施。

如果直接 merger parent firms A 与 B，就可以内生化四个 payoff components。但主模型有意把 full merger 放在一边：作者设想 a、b 相对于 core assets A、B 很小，而合并母公司会产生未显式建模的 integration costs，例如统一 control systems/cultures、克服 communication barriers，以及让 decision makers 离后果更远。

QUALIFICATION

这并不意味着 merger 永远低效。§4 最后明确说明：如果 a、b 相对 A、B 足够重要，best second-best alliance 的 inefficiency 可能大于 parent integration cost，此时 merger 可以成为最优选择。

Footnote 5 的另一种解释

作者还给出另一种理解：把 πA(s) 与 πB(s) 视为分别流向 A、B 的 inalienable private benefits。这样一来，就不可能把全部 decision rights 与全部 payoffs 都集中到同一 party，因此仅靠重新配置 project assets 也无法实现完全 internalization。

Source: §3b · PDF pp. 11–12（含 footnote 5）；§4 末尾 · PDF p. 26

4. Governance Structures 的定义

4.1 Asset Ownership：四类结构、九种配置

在 §3c 中，一个 project asset 的 ownership 把 decision right 与 direct payoff 捆绑在一起。因此重新分配 a 与 b，会同时改变 control 和 controller 内生化的 payoff。即使只有两个可转移 project assets，也已经形成九种配置。

Unstructured Collaboration

A 与 B 分别保留 project assets（也可以 swap）。若 A owns a、B owns b，则双方都必须愿意合作：πA+πa>0 且 πB+πb>0。

Acquisition

其中一个 parent 拥有两个 project assets。若 A acquisition，则 A 控制两个 decisions 并取得两个 direct project payoffs，而 B 的 spillover 不进入 A 的 implementation criterion。

Total Divestiture

A 与 B 把 a、b 都转给 third party C。由于 πa,πb>0，C 在所有 states 都希望实施，并忽略两家 parents 的 spillovers。

Strategic Divestiture

只有一个 project asset 转给 C。于是一个 parent 仍然拥有 veto，而 C 总是支持 proceeding。配合 asset swap 可生成对称变体。

4.2 Contracting Over Decision Rights：Licensing

下一步把 decision right 与 asset ownership 分开。Contract 可以把某项 asset 的使用决定权交给另一方，同时 asset owner 保留 direct payoff。作者把这种安排定义为 license agreement。

IMPORTANT DISTINCTION

Decision ≠ decision right。实际发生的 action 依然 noncontractible；能够 contract 的是“state 出现以后谁有权采取这个 action”。

4.3 Contracting Over Payoffs：Royalty Agreements

如果 direct project payoffs 在结果出现以后可 contract，governance menu 还可以更丰富。作者先否定另一种设定：如果 payoff stream 本身不可验证，却把全部 return rights 与 residual decision rights 分开，那么 controller 可能把无法验证的 returns 转移给自己，因此这种分离不可信。这一逻辑承接 Holmstrom and Tirole (1989)。

MODELING CHOICE

因此论文假设 πa、πb 可 contract，但 πA(s)、πB(s) 仍然是 noncontractible private benefits。这样可以引入 royalties，同时保留核心 spillover problem。

5. Efficient Governance：比较不同 Implementation Regions

5.1 同一个 Geometry，不同的 Decision Rules

令 x=πA(s)，y=πB(s)，f(x,y) 为它们的 joint density。每一种 governance structure 都对应 (x,y) 平面中的一个 implementation region。该 structure 的 expected surplus，就是 total project surplus x+y+πa+πb 在其 implementation region 上的期望。

Expected surplus · 论文 §4 各积分式的等价紧凑写法
S(x,y) = x + y + πa + πb
Vg = ∬𝓘g S(x,y) f(x,y) dx dy

Interpretation. 𝓘g 表示 governance form g 所产生的 implementation region。原论文分别为 First Best、Unstructured Collaboration、Acquisition、Total/Strategic Divestiture、Licensing 以及两类 royalty structures 写出带有不同积分边界的 value expressions；这里用完全等价的 compact notation 把它们统一表示，便于理解比较逻辑。

ANALYTICAL SYNTHESIS · EQUIVALENT NOTATION
First Best
x + y + πa + πb > 0

边界是 diagonal，因为所有 payoff components 都被内生化。

Unstructured Collaboration
x + πa > 0   and   y + πb > 0

A 与 B 都是 veto players，因此 implementation region 是两个条件的交集，可能相对 first best 发生 under-implementation。

Royalty + Unstructured Collaboration
x + α(πa+πb) > 0   and   y + (1−α)(πa+πb) > 0

改变 α 可以移动两个 veto thresholds，但一般无法复制 first-best 的 diagonal frontier。

Threshold explorer

选择 governance form，查看 decisive party 内生化哪些 payoff components。这是对 Figures 7–14 的学习型重构，不是 numerical simulation。

Implement iff x + y + πa + πb > 0。所有 spillovers 与 direct project payoffs 都进入 criterion。

5.3 核心 Second-Best Result

AUTHOR'S RESULT

Figures 8–14 的 implementation regions 表明：对所有 joint distributions f(x,y)，不存在一种 governance structure 支配所有其他形式；反过来，每一种被分析的形式都可以在某些环境中成为 surplus-maximizing feasible structure。因此现实中的 organizational-form multiplicity 并不令人意外。

DO NOT OVERSTATE

论文没有得到类似“spillovers 高时 licensing 一定优于 acquisition”的 universal ranking。除非进一步对 spillover distributions 和 institutional details 加结构，否则模型刻意不做这种预测。

5.4 如何得到 Sharp Predictions？

要在具体 setting 中比较 organizational forms，研究者必须知道：哪些 decisions truly noncontractible；每项 decision 如何影响各方；state 如何改变这些 consequences；不同 states 的 probability distribution 是什么。

Biotech control illustration

若 development 对 biotech 在几乎所有 states 都有 positive spillover，把 control 给 biotech 会倾向于在所有 states 都实施。当 pharma 的 negative spillovers 又大又常见时，这可能低效。

Opposite control

反过来，把 control 给 pharma 可能产生 under-implementation，因为 pharma 不内生化 biotech 的 positive spillover。因此 optimal control location 取决于 spillover distribution。

MERGER RETURNS

由于 alliance forms 一般都不是 first-best，当 a、b 相对 A、B 足够重要时，second-best alliance 的 inefficiency 可能超过 combining parent firms 的 integration cost，于是 full merger 可能更优。

Source: §4 · PDF pp. 25–26

6. 超越 Unique Control：Joint Ventures 与 Relationships

6.1 Joint Control 与 Adaptation Problem

Sections 3–4 都要求 unique control：每个 asset 或 decision right 恰好由一方拥有或控制。现实 alliances 经常采用 shared control，尤其是 joint ventures，因此 §5a 讨论多方共同参与 decision process 时会发生什么。

49–49–2 voting example

设 A 持有 joint venture 49%，B 持有 49%，C 持有 2%。C 获得一部分 project payoff；由于 direct project payoffs 为正，C 总是 vote to proceed。在 majority voting 下，项目只有在 A 与 B 都投 no 时才会停止。因此其 implementation pattern 不同于前面的 unique-control structures。

SUBTLE CONTRACTIBILITY ISSUE

如果 voting outcome 要约束实际负责 implementation 的人，那么“是否实施”的 voting procedure 本身必须可 enforce。因此作者明确不把这个例子当作完整的 joint-venture theory。

Better adaptation?

作者更广泛的理解是：复杂 joint-venture governance 可能专门用来改善 ex post adaptation。Manager 针对 state 灵活行动，board 在事后评价其 decision。实现这一点需要 expert board members、measurement/control systems 和 incentive arrangements，因此成本不低；只有 adaptation value 很高时，这套机制才更可能最优。

Source: §5a · PDF pp. 27–28

6.2 Relationships 与 Self-Enforcing Relational Contracts

One-shot alliance 无法用未来后果约束 noncontractible actions；重复互动则可以。如果行为对双方 observable，relational contract 可以依靠 future surplus 自我执行：今天 deviation 的代价是失去未来关系价值。当 “shadow of the future” 很大时，这种机制更强。

1 · Long-lived alliance

同一 alliance 中持续互动，使当前 opportunism 影响未来。论文用持续数十年、并多次 restructuring 的 Fuji–Xerox Asia-Pacific relationship 作为例子。

2 · Repeated alliance partners

同一对 firms 可以多次签 alliances，因此当前行为会影响未来 bilateral opportunities。

3 · Indirect network ties

即使两家 firms 从未直接合作，也可能通过 common partners 交换信息，因此 reputation 可以沿 alliance network 传播。

MECHANISM

Observable-but-nonverifiable actions 无法由 court enforce，却能进入 self-enforcing informal agreement，只要 continuing relationship 的未来收益大于当前 deviation 的 short-run gain。

Source: §5b · PDF pp. 28–30

8.3 Authors' Limitations 与 Scope Conditions

Broad framework, weak generic predictions

作者明确承认：general model 不能在没有更多 institutional structure 和 spillover distribution 假设时预测具体行业选择哪一种 form。

Joint control is only sketched

One-shot model 假设 unique control；实际 joint ventures 包含 decision procedures、managers、boards、measurement 与 relational elements，需要更丰富理论。

Relationships are an extension

Relational contracting 只是 conceptual extension，并与 descriptive evidence 联系；它没有完全整合进主 governance optimization。

Biotech evidence is motivating

Database 证明 prevalence 与 network density，但没有 causal test 哪种 governance structure 更有效。

8.4 Analytical Limitations

ANALYTICAL SYNTHESIS

Selection into governance：descriptive evidence 无法区分 “governance 导致更好 outcome” 与 “firms 因为预见了特定 spillover states 才选择该 governance”。严谨 empirical test 需要 governance/contractibility 的可识别 variation 与 outcome data。

ANALYTICAL SYNTHESIS

Endogenous formation and investment are absent：模型从已经存在的 potential project 开始，重点是 implementation；没有联合建模 partner search、alliance formation、relationship-specific investment、renegotiation、termination 或 learning。

ANALYTICAL SYNTHESIS

Contractibility is coarse：现实 contracts 有许多 decision rights、milestones、vetoes、staged payments、field-of-use restrictions、options 与 dispute mechanisms。若把 decisions 建成 partially contractible vector，可能得到更 sharp predictions。

9. Research Implications / Extensions

RESEARCH EXTENSION

下面是基于本文 framework 的 learning-oriented extensions，不是作者已经证明的结论。

Dynamic governance transitions

让 partnerships 随对 spillovers 与 adaptation needs 的 beliefs 更新，在 procurement、collaboration、licensing、shared control、acquisition 与 termination 之间内生转换。

Endogenous partner search and matching

让 firms 根据 expected complementarity、spillover covariance 与 feasible governance contracts 选择 partners。

Bargaining over governance

区分 total-surplus-maximizing governance 与 transfers/control 的 bargaining；outside options 可能决定哪些 efficient 或 inefficient allocations 实际可实施。

Empirical contract design

把真实 contracts 编码成 asset ownership、veto/decision rights、milestone rights、royalties、options、termination clauses，再与 ex ante adaptation-risk proxies 联系。

Network reputation

显式建模 indirect ties，使对一个 partner 的 deviation 改变与其他 partners 的 continuation values；biotech dense network 使这一机制具有 empirical plausibility。

Joint-venture adaptation technology

内生化 boards、measurement systems、delegation 与 expert control 的成本，预测何时 firms 愿意为 richer governance 付费，而不是简单 assign unique control。

Q1. 为什么 strategic alliances 是 “bridges”，而不只是较小的 firms？

CORE · LITERATURE
Hint：想想在不转移整个 firm 的情况下，哪些东西可以跨越 fixed boundary。
Suggested Answer：本文把 alliances 看成可以跨 firm boundaries 重新配置 project assets、decision rights 与 payoffs 的 contractual structures，而 parent firms 仍保持独立。因此 bridge 可以改变 control 和 incentives，却不要求 full integration。

Common Mistake：认为所有 hybrid governance 都必须改变 ownership；licensing 可以保持 ownership 不变而移动 decision rights。

Why This Matters：这就是本文相对 market-versus-firm literature 的核心概念贡献。复习 §1.1。

Q2. 本文把哪种 friction 放在比 standard hold-up 更核心的位置？

MECHANISM
Hint：关注 state 已知以后、implementation 之前发生什么。
Suggested Answer：核心是 state-dependent spillovers 与 ex post noncontractibility of decisions。State observable but not verifiable，关键 decisions 无法 contract，也来不及 renegotiate，于是 decision-right holder 按 private objective 行动，忽略部分 external effects。

Common Mistake：把本文写成 relationship-specific investment underinvestment model。Practitioners 明显更强调 spillovers 与 ex post adaptation。

Why This Matters：这解释了本文与 canonical property-rights hold-up formulation 的不同。复习 §1.2 与 §3.2。

Q3. 不看正文，推导 Unstructured Collaboration 的 implementation rule。

FORMAL MODEL
Hint：A 与 B 都必须同意。分别问每一方实施时私下得到什么。
Suggested Answer：若 A owns a、B owns b，A 只有在 πA(s)+πa>0 时同意，B 只有在 πB(s)+πb>0 时同意。因为 coordinated use 需要双方，所以两个 inequalities 必须同时成立。

Common Mistake：直接写 first-best condition πA+πB+πa+πb>0；关键恰恰在于没有任何单个 decision maker 内生化这个总和。

Why This Matters：一旦理解这个 threshold，Figures 7–14 的 implementation-region method 就很直观。复习 §4.1 与 §5.1。

Q4. 为什么 Acquisition 与 Total Divestiture 会犯不同方向的错误？

MECHANISM · FORMAL MODEL
Hint：列出 acquisition 后 A 内生化什么，以及 total divestiture 后 C 内生化什么。
Suggested Answer：Acquisition by A 内生化 x 与两项 direct payoffs，却忽略 y，所以取决于 B spillover 的符号与大小，可能 over- 或 under-implement。Total Divestiture 中 C 只获得正 direct payoffs，因此永远实施；当 parent spillovers 足够负使 total surplus 为负时，它一定 over-implement。

Common Mistake：把“更多 integration”当成单调更高 efficiency。这里每种 form 只是内生化不同 subset of surplus。

Why This Matters：说明 governance 不是一条单一 integration continuum。复习 §5.2。

Q5. Licensing 提供了 asset ownership 本身做不到的什么东西？

GOVERNANCE DESIGN
Hint：把“谁选择”与“谁拿到 asset payoff”分开。
Suggested Answer：Licensing 可以在不转移 ownership/direct payoff 的情况下转移 decision right，因此创建出 di 与 πi 不必一起移动的 incentive configurations。

Common Mistake：认为 realized action 本身变得 contractible；事实上只是 authority 的 allocation 可 contract，decision 仍然 noncontractible。

Why This Matters：这是 fixed firm boundary 上 contractual bridge 的 formal meaning。复习 §4.2。

Q6. 为什么每种 form 都可能是 second-best，但一般没有一种是 first-best？

CORE RESULT
Hint：先比较每种 form 的 implementation frontier 与 first-best diagonal，再考虑 probability mass 在哪里。
Suggested Answer：不同 governance 让 controller 内生化不同 payoff components，因此产生不同 implementation frontiers；这些 frontiers 一般都不等于 total-surplus first-best frontier。但每一种 mismatch 的 expected loss 取决于 f(x,y)。只要某个 environment 的 probability mass 集中在某种 rule 相对少犯高成本错误的 states，该 rule 就可以成为最优 feasible second-best。

Common Mistake：把 second-best 理解成固定 ranking 中“第二名”；这里是特定 constraints/environment 下最优 feasible governance。

Why This Matters：这是整篇论文的 central theoretical conclusion。复习 §5.3。

Q7. Biotech data 证明了什么，又没有证明什么？

EVIDENCE · IDENTIFICATION
Hint：区分 descriptive prevalence/network evidence 与 causal governance effect。
Suggested Answer：数据证明 alliance network 很 dense、governance forms/objectives 很多样，并存在 long-lived/repeated ties；这些事实支撑 feasible set 与 relational extension。它们没有识别某种 governance 是否因果提高 surplus，也没有识别某个 alliance 为什么选择某条 contract。

Common Mistake：因为 Table 2 里 licensing 更常见，就把它解释成更 efficient。

Why This Matters：避免把 empirical motivation 与 causal identification 混为一谈。复习 §2。

Q8. Joint Control 与 Relational Contracts 怎样用不同方法处理同一个 adaptation problem？

EXTENSION · CRITIQUE
Hint：一个建立 internal decision process；另一个依赖 future continuation value。
Suggested Answer：Joint control 通过 manager、board、voting、measurement、evaluation 等 costly institutional machinery，让组织能够根据 realized state 调整 decision。Relational contracting 则利用 future bilateral/network surplus，使 observable nonverifiable behavior self-enforcing。两者都试图超越 one-shot fixed control rights，改善 ex post adaptation。

Common Mistake：把 joint venture 简化为 50/50 asset ownership；本文强调的是其 decision procedure 与 adaptive governance。

Why This Matters：这两项 extension 指向更完整的 alliance governance theory。复习 §6。

12. What Should I Remember?

8 个必须记住的点

  1. Strategic alliances 被建模为独立 firms 之间 assets、decision rights 与 payoffs 的配置。
  2. 核心 frictions 是 state-dependent spillovers 与 noncontractible ex post decisions，而不是主要来自 ex ante hold-up。
  3. Governance 在 s 之前选择；s 被观察；controllers 行动；payoffs 实现；中间没有时间 ex post recontract。
  4. First best：πA+πB+πa+πb>0 时实施。
  5. Ownership、licensing、royalties 改变哪些 payoff components 进入 controller 的 private implementation criterion。
  6. 论文研究的每一种 form 都能在某个 environment 下成为 second-best；没有一种一般 first-best。
  7. Biotech data 证明 dense networks、heterogeneous governance、long-lived/repeated ties，但不证明 causal efficiency effect。
  8. Joint ventures 与 relational contracts 是处理剩余 adaptation problem 的自然方向。
Authors' conclusion · 论文明确列出的三个 goals
  1. 记录可被称为 strategic alliances 的 plethora of governance structures。
  2. 基于 practitioner observations 建立一个简单 framework，用 assets、decision rights 与 payoffs 的配置来定义并潜在解释这些多样形式。
  3. 超越 one-shot framework，进入 joint ventures 与 relational contracting；作者希望结合更丰富的 institutional knowledge 与 data 后，可以得到更具体、可检验的 predictions。
Source: §6 Conclusion · PDF p. 31
One-Sentence Summary

当 rapid, noncontractible decisions 会给其他 firms 产生 externalities 时，alliance governance 的本质是决定谁内生化哪一部分 surplus，因此不同 contractual bridges 会在不同 environments 中最优。

Core Mechanism

Allocation of control/payoffs → private implementation threshold → state-contingent implementation errors → expected surplus ranking。

Most Important Result

No universal governance winner：每一种 feasible form 都能在合适的 f(x,y) 下成为 second-best。

Biggest Contribution

用统一 language 联系 ownership changes、licensing、royalties、collaborations、divestitures，以及进一步的 joint/relational governance。

Biggest Limitation

Framework 刻意 broad，因此不能自己产生 setting-free 的 sharp empirical predictions。

Biggest Open Question

如何建模并测量现实中的 adaptive institutions 与 relationships，使 governance predictions 真正可检验？
